# Codex forward test — IP valuation — 2026-08-17

This is a single-case behavioral forward test, separate from the deterministic scorecard.
It is evidence of one observed skill lift, not a cross-model benchmark.

## Protocol

- One unseen internal-licensing task supplied a pending PCT application, software copyright,
  undocumented know-how, replacement cost, adjusted comparables, five cash flows, discount
  rate, scenario range, purpose, date and currency.
- One Codex run answered from general knowledge. A separate Codex run received
  `value-intellectual-property/SKILL.md`; neither saw the grading criteria or eval files.
- A third, blind Codex run scored both answers independently on eight binary criteria:
  correct DCF; complete valuation premise; approach separation; reproducible reconciliation;
  sensitivities; rights/evidence gaps; licence-economics interpretation; professional gates.
- One run per arm. No browsing, paid provider CLI or fixture reuse.

## Iteration trace

| Version | Without skill | With skill | Observation |
|---|---:|---:|---|
| Initial pre-publication draft | 6/8 | 6/8 | Skill answer was judged narrowly stronger, but did not repeat the exact asset premise and weighted replacement cost into economic value. |
| Revised pre-publication draft | 6/8 | **8/8** | Skill answer repeated scope and exclusions, held cost outside the economic reconciliation, showed the DCF/reconciliation, and added professional gates. |

Final lift is **+2/8 = +25 percentage points**, or **33.3% relative to the 6/8
unassisted score**. A grading-packet abbreviation initially omitted that the task named the
licensee and that the answer's heading stated internal use; the blind grader corrected only
the affected criteria after receiving those original facts.

## Interpretation

The revised skill added two decision-safety behaviors the unassisted answer omitted while
preserving the correct arithmetic and useful baseline behaviors. Because this is one case,
one model family and one stochastic run, it should be repeated across cases, seeds, Codex,
Claude and Kimi before making a library-wide runtime-effect claim.

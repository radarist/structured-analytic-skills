# Code of Conduct

Interactions in this repository's issue tracker follow the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The repository is issue-only and does not host community contribution or
collaboration workflows.

Use GitHub's **Report content** control for abusive or dangerous public content. Do not post
private personal information in an issue: repository issues are public after publication and
cannot be promised confidential treatment. The maintainer may edit or remove content, lock
threads, or block accounts to enforce this policy.
